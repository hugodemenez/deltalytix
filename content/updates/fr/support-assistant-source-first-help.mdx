# Un support qui vérifie le produit avant de répondre

La [page Support](/fr/support) explique plus clairement comment une réponse est obtenue et comment joindre une personne si nécessaire. Pour les questions sur le fonctionnement de Deltalytix, l'assistant recherche et lit d'abord les fichiers sources pertinents du produit, plutôt que de s'appuyer uniquement sur les notes de mise à jour. Les étapes visibles de recherche, de lecture et de raisonnement permettent de suivre cette vérification.

![Conversation de support montrant la recherche dans le code, la lecture des fichiers, le raisonnement et une réponse sourcée](/updates/pr-439/fr/support-source-investigation.png)

## Corrigez la question, sans recommencer toute la discussion

Utilisez **Modifier** sur une question textuelle précédente pour la préciser. L'interface indique les réponses suivantes qui seront supprimées, puis reprend l'échange à partir du message corrigé : les réponses fondées sur l'ancienne formulation ne restent pas dans la conversation. Vous pouvez toujours joindre une image pour montrer ce que vous voyez.

![Question de support précédente en mode modification avec les réponses suivantes marquées pour suppression](/updates/pr-439/fr/support-question-edit.png)

## L'équipe support reste accessible en une action

Sélectionnez **Remplir une demande de support via le formulaire** dans le nouvel en-tête pour contacter directement l'équipe. L'assistant peut également préparer un résumé et proposer **Ouvrir le formulaire de contact** ; si vous êtes connecté, votre adresse e-mail peut déjà être renseignée. Selon la taille de l'écran, le formulaire s'ouvre dans une fenêtre ou un tiroir mobile, et le lien Discord reste disponible.

![Formulaire de contact du support rempli avec des informations synthétiques et non envoyé](/updates/pr-439/fr/support-contact-form.png)

Les réponses de l'IA dépendent toujours de la disponibilité du service et peuvent contenir des erreurs. L'analyse des sources apporte des éléments plus concrets, tandis que le contact direct offre une suite claire lorsqu'une personne doit prendre le relais.
