# Gérez vos jetons d'API et applications autorisées dans les Paramètres

[Paramètres → Connexions](/fr/dashboard/settings#connections) affiche désormais tout ce qui peut accéder à votre compte via l'API.

![Paramètres Connexions avec un jeton d'API, une application autorisée et le lien vers la documentation développeur](/updates/pr-543/fr/settings-connections-api.png)

- **Jetons d'API** en premier. Avec **Créer un jeton**, choisissez un nom et des scopes, puis copiez le jeton tout de suite : il ne s'affiche qu'une fois. Chaque ligne indique ses scopes, sa date de création et sa dernière utilisation.
- **Applications autorisées** liste les applications que vous avez approuvées, avec leurs scopes et leur dernière utilisation. **Révoquer** coupe l'accès immédiatement ; il faudra l'autoriser à nouveau pour la réutiliser.

Vous développez une intégration ? Le lien en bas de la section mène à la [documentation développeur](/fr/docs) et à vos applications. L'accès API n'est plus dans le menu du compte : tout se trouve ici.
