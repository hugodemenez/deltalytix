# Synchronisation côté serveur avec Rithmic R | Protocol

Les traders disposant d'un accès Rithmic R | Protocol approuvé bénéficient d'un nouveau parcours côté serveur pour importer leurs ordres et exécutions dans Deltalytix.

Depuis [Connexions](/fr/dashboard/connections), choisissez **Ajouter une connexion Rithmic Protocol**, sélectionnez le système Rithmic disponible pour votre déploiement, puis saisissez vos identifiants. Deltalytix détecte les comptes hébergés auxquels vous avez accès, vous permet de choisir ceux à connecter et transforme les exécutions synchronisées en trades dans le journal.

Cette intégration est distincte de la synchronisation Rithmic existante et ne la remplace pas. Elle nécessite un point d'accès Protocol configuré, des identifiants valides et les autorisations R | Protocol de votre broker ou prop firm ; tous les comptes Rithmic ne sont donc pas éligibles. Les systèmes proposés peuvent aussi varier selon le déploiement.

Si votre compte est autorisé, [ouvrez Connexions](/fr/dashboard/connections) pour ajouter **Rithmic Protocol** et démarrer la synchronisation.
