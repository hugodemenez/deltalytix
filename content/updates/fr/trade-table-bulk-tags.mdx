# Tags en masse dans le tableau de revue des trades

Sur [le tableau de bord](/fr/dashboard), cochez une ou plusieurs lignes dans **Revue des trades**, puis utilisez **Ajouter un tag** ou **Retirer un tag**. Le même popover de recherche que le `+` par ligne permet de choisir un tag existant ou d'en créer un sur place.

Ajouter un tag conserve les autres tags de chaque trade sélectionné. Retirer un tag n'enlève que ce nom. Les lignes groupées affichent l'union des tags de leurs sous-trades, et taguer un groupe fusionne maintenant ce tag sur chaque sous-trade au lieu de copier la liste du premier trade sur les autres.
