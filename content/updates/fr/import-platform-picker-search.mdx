# Recherchez une plateforme dans le sélecteur d'import

**Ajouter avec un fichier** sur **Tableau de bord → Connexions** s'ouvre désormais avec un champ de recherche. Tapez quelques lettres pour filtrer la liste par nom ou description de plateforme — « rithmic », « csv », « pdf » — et validez le résultat avec Entrée au lieu de parcourir toutes les plateformes prises en charge.

![Le sélecteur d'import avec « rithmic » saisi, réduisant la liste à Performance Rithmic et Ordres Rithmic](/updates/pr-394/fr/import-picker-search.png)

Les flèches du clavier permettent de circuler entre les résultats, et une recherche sans correspondance affiche **Aucun type d'import trouvé.** plutôt qu'un panneau vide. La recherche fonctionne aussi lorsque vous rouvrez le sélecteur depuis le bouton de la plateforme choisie pour passer à un autre import.

[Ouvrez la page Connexions](/fr/dashboard/connections) pour l'essayer.
