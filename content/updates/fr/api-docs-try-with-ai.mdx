# Essayez la documentation API avec Claude, ChatGPT ou Grok

L'en-tête de la [documentation API](/fr/docs) propose **Essayer avec l’IA**, sous l'introduction, en français comme en anglais. **Claude**, **ChatGPT** et **Grok** ouvrent chacun cet assistant dans un nouvel onglet.

![En-tête de la documentation avec Essayer avec l’IA et les boutons Claude, ChatGPT et Grok](/updates/pr-575/fr/docs-header-try-with-ai.png)

Le message renvoie vers la documentation et le document OpenAPI de ce site, et demande un premier appel pas à pas : créer un jeton, s'authentifier, puis des exemples curl.
