# Le drawdown des comptes avec buffer suit le profit réellement compté

Sur un compte avec buffer, le solde ne compte que le profit au-delà du buffer, mais le drawdown était encore calculé sur l'équité totale. Un compte trailing pouvait donc apparaître en violation juste après avoir franchi le buffer, ou un compte statique masquer une vraie violation après être repassé sous le buffer.

Le drawdown utilise maintenant la même courbe que le solde : le seuil trailing et la perte restante correspondent à ce que le compte compte vraiment. Les comptes sans buffer ne changent pas.
