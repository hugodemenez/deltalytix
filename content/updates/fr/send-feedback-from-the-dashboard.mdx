# Envoyez vos retours sans quitter le tableau de bord

La nouvelle action **Envoyer un retour ou signaler un bug** dans la barre de navigation vous permet de contacter directement l'équipe Deltalytix sans interrompre votre travail.

Ouvrez **Partagez votre avis**, saisissez le message obligatoire et, si vous le souhaitez, ajoutez un email valide pour recevoir une réponse. Après l'envoi, la boîte de dialogue confirme la réception de votre retour. Si vous avez renseigné une adresse, Deltalytix envoie également un accusé de réception par email.

[Ouvrir le tableau de bord](/fr/dashboard) et sélectionner l'icône de message dans la barre de navigation pour proposer une idée ou signaler un problème.
