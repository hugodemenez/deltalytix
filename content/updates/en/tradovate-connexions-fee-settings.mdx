# Tradovate fee settings now live on Connections

On [Connections](/en/dashboard/connections), each Tradovate row now has a settings control next to **Sync now**. It opens **Fee config for {account}** — Commission, Exchange, Clearing, NFA, Brokerage, and Order routing — with **Select all**, **Cancel**, and **Save**. Default is still commission only.

If you have not chosen yet, **Sync now**, **Sync all**, or **Choose fees** opens **Which fees match your platform?** An illustrative **3 MNQ** round-turn shows **Commission only** at $2.34 versus **All fees** at $5.70. Those amounts are an example, not a live quote. **Skip — use commission only** saves the default and does not ask again; the gear stays available if you change your mind.

This is the Connections follow-up to [choosing which Tradovate fees count](/en/updates/tradovate-sync-fee-type-options). The older Import → Tradovate sync checklist is unchanged. Extra fee lines are opt-in — commission-only stays the default until you pick otherwise.
