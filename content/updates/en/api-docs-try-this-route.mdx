# Try this route loads each documented call, and the new token stays visible

On the [API documentation](/en/docs), **Try this route** now loads the live operation for each documented route, including guides the panel used to mark as missing from the API document. You can send the request from the guide. The browser step that approves an app, a file upload, and a form-encoded body still cannot be sent from the panel; those guides point to the documented example.

**Generate docs token**, when you are signed in, and **Use demo token**, for read-only sample data, used to close the sheet at once and leave the token masked. The sheet now stays open with the token in view next to **Copy** until you close it. Creating the token works as before, and it is still shown only while that sheet is open.
