# Use another account on the app consent screen

If an app asks to access Deltalytix while the browser is signed into another account, **Use another account** sits under the **Signed in as** line. It signs you out, sends you to sign-in, and brings you back to this same consent screen. The return is only this authorization request. Dashboard settings do not include the link.
