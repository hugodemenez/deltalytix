# New connections start with a daily after-close sync

A new connection that can sync on a schedule now starts with a daily sync at **After close**, instead of manual only. Change the time or turn the schedule off on [Connections](/en/dashboard/connections). Presets and intervals are the ones in [Set the right synchronization rhythm for each connection](/en/updates/flexible-connection-sync-schedules).

The default is set only when the connection is created, and only for Tradovate, DxFeed, Rithmic Protocol, Interactive Brokers, and IG. A time already chosen at creation is kept. Connections you already have, including ones set to manual, stay as they are. Thor and the legacy Rithmic connection remain manual-only.
