# Dark, localized previews for shared links

Deltalytix links now look like Deltalytix before they are opened. Links to the site, referrals, updates, shared pages, and **Connections** display a consistent dark, chart-led preview with readable contrast.

![Dark Open Graph preview card for the localized changelog entry](/updates/pr-378/en/dark-localized-link-preview.png)

Titles, descriptions, and alternative text are localized where available, so recipients get a preview that matches the language of the page. This update changes social and chat link cards—not the dashboard itself.

Paste a fresh Deltalytix link into a service that supports Open Graph previews to see the new design. Some services cache older cards, so an existing link may take time to refresh.
