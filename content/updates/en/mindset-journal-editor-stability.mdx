# Mindset journals no longer crash on open

Adding the **Mindset** widget, and opening a calendar day's daily comment, no longer crashes. Both now use a lighter journal editor with headings, lists, quotes, image upload, the AI menu, and fullscreen.

One limitation to know about: this editor doesn't offer a table insert control. Existing journal entries that already contain a table still display, but you can't add a new one from the toolbar.

[Open the dashboard](/en/dashboard), add **Mindset**, and open the journal pane.
