# Bulk tags in the trade review table

On [the dashboard](/en/dashboard), tick one or more rows in **trade review**, then use **Add tag** or **Remove tag**. The same search popover as the per-row `+` control lets you pick an existing tag or create one inline.

Adding a tag keeps every selected trade's other tags. Removing a tag strips only that name. Grouped rows show the union of their sub-trade tags, and tagging a group now merges that one tag onto each sub-trade instead of copying the first trade's list onto the rest.
