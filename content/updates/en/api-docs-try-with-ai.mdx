# Try the API docs with Claude, ChatGPT, or Grok

The header of the [API documentation](/en/docs) now includes **Try it with AI**, under the introduction, in English and in French. **Claude**, **ChatGPT**, and **Grok** each open that assistant in a new tab.

![Docs header with Try it with AI and buttons for Claude, ChatGPT, and Grok](/updates/pr-575/en/docs-header-try-with-ai.png)

The prompt points at this site's docs and OpenAPI document and asks for a step-by-step first call: create a token, authenticate, then curl examples.
